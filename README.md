# Salán Producciones Web

Web corporativa para **Salán Producciones**, empresa vinculada a la producción de eventos musicales y culturales.

---

## Qué es

Este proyecto nace para modernizar la presencia online de la empresa y reducir la dependencia de flujos más lentos basados en WordPress, editores visuales o cambios manuales desde hosting tradicional.

La idea es tener una web más controlable, rápida y fácil de evolucionar, conectada con una forma de trabajo más moderna basada en GitHub, despliegues automáticos y estructura de contenidos clara.

---

## Objetivo

Crear una base web que permita:

- presentar la empresa,
- mostrar eventos, giras o proyectos musicales,
- publicar páginas específicas para campañas,
- preparar landings para promoción,
- integrar formularios, analítica y píxeles,
- y facilitar cambios rápidos sin depender de procesos manuales pesados.

---

## Qué resuelve

En una empresa de eventos, muchas veces hace falta publicar información rápido: fechas, ciudades, enlaces de entradas, materiales promocionales, formularios o páginas específicas para campañas.

Este proyecto intenta resolver esa necesidad con una arquitectura más flexible y mantenible.

---

## Stack y herramientas

- GitHub como repositorio de trabajo.
- Vercel como plataforma de despliegue.
- Frontend moderno.
- Preparación para analítica y campañas digitales.
- Organización de contenidos orientada a eventos.

---

## Qué estoy practicando con este proyecto

- Migración desde flujos tradicionales a despliegues modernos.
- Organización web para una empresa real.
- Publicación rápida de páginas y landings.
- Integración de marketing digital, analítica y tecnología.
- Aplicación práctica de automatización en una empresa familiar.

---
